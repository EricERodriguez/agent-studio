# Tools and Skills

Agents become powerful when connected to tools and skills. This page explains how to register and use tools (APIs, functions, or capabilities) within Agent Studio.

## Registering a tool

1. Open the **Capabilities** tab.
2. Click **Register Tool** and provide a name and connection details.
3. Map required inputs and outputs for the tool.

## Best practices

- Name tools clearly (e.g., `csv_parse`, `send_email`).
- Limit permissions to only what's necessary.
- Add examples and usage notes in the tool description.

## Learn more

- Browse the [Visual Dashboard](./visual-dashboard.md) to inspect registered tools and activity.
- See [Workflows](./workflows.md) to connect tools across agents.
