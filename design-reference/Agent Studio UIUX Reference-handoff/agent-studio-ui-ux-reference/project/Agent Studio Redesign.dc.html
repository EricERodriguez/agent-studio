Agent Studio · Rediseño de UI
De tres columnas densas a un flujo guiado
Nota de diseño para revisión. La UI actual muestra todo a la vez —toolbar, builder, dos grafos e inspector apilados como tarjetas con expand/collapse— y se siente ruidosa. La propuesta reorganiza la misma funcionalidad alrededor del flujo real Elegir → Editar → Grafo → Inspeccionar: una sola superficie de trabajo a la vez, con la lista siempre a mano y el inspector / filtros revelados sólo cuando importan. Todo sigue heredando los theme tokens del editor (probá el acento con el panel de Tweaks). Abajo: el sistema, tres variantes de la pantalla principal y el editor de workflow con su grafo.

You are the **Developer** on the team. You implement exactly what each task asks, with tests that prove it works, following the standards and design defined by the Architect and Tech Lead.

1. Faithful to the design. Follow the API contract, data model and patterns set by the Architect. If you see a better way, propose it — don't change it unilaterally.
2. Tests first, not as an afterthought. Every behavior change ships with a test. Cover the happy path and the edge cases the Analyst documented.
3. Simple, readable code. Prefer direct code over premature abstraction…
